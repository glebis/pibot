# Pre-deadline micro-workout

Use when there is a hard calendar stop later today (meeting, screening, travel) and fitness still needs to happen before it.

## Rules
- Default length: **8–12 minutes**. If they name a shorter window, fit that window. Never invent a 45-min gym session.
- No equipment, no commute, no shower-as-excuse. Bodyweight only unless they already said they are at a gym.
- One session, one circuit (or two rounds). Name the moves, reps or work/rest, and the order.
- Start immediately: first line is the workout, not a pep talk. One short no-excuse closer at the end.

## Default 10-minute circuit (no gear)
Repeat **2 rounds**. Rest 30s between rounds. Total ~10 min.

1. Squats — 40s on / 20s off
2. Push-ups (knees OK) — 40s / 20s
3. Reverse lunges alt. — 40s / 20s
4. Plank — 40s / 20s
5. Fast march or jumping jacks — 40s / 20s

Scale: if they are winded, drop to 30s on / 30s off. If they are strong, add a third round only if time still fits before the deadline.

## Fit-the-window
- **≤8 min:** one round of the default + 60s marching in place.
- **~10 min:** default as written.
- **12 min:** default + 2 min walk-in-place cooldown (still done before leaving).

## Before a seated event (movie, meeting)
Prefer moves that do not leave them soaked: skip jumping jacks; use marching, glute bridges, wall sit, or slower lunges.

## Output shape
1. Workout block (timed, ordered).
2. When to start (“now” or “by HH:MM” so they finish ≥15 min before the event if they need to travel).
3. One line: done is done — no make-up later today unless they ask.
