# Focus block

1. Calendar first — skip if a meeting starts within the block.
2. Name **one** outcome in a verb phrase (“draft Herabsetzung email”, not “taxes”).
3. Pick length: 25m / 50m / 90m. Default 50m if they don’t care.
4. `schedule_create` the end bell. Optional 5m warning.
5. At the bell: one line — done / continue / break. Don’t recap the day.

If the task is huge, cut to a 10m start, then offer a real block.
