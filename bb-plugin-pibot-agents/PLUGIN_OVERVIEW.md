Visualize PiBot agents and delegated work inside bb, with text and voice chat.

The PiBot agents page shows the agent roster, active turns, durable runs and a
real process tree. Create reactive agents and cancel named runs. Open an
existing canonical chat binding to type, dictate an editable message, or start
a live audio call using the configured PiBot voice service.

Agent permissions remain in PiBot. Tools are opt-in, approvals stay in the
canonical chat, and service credentials stay in secret plugin settings. This
plugin requires separately configured PiBot dashboard/voice services and does
not start or deploy them.
